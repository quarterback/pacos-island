# After action record: Paco's Island v0.5, first build

**Date:** November 16, 2026
**Accountable human:** Ron Bronson, game owner
**Scope:** Spec and first playable build, put in a new repo for viewing and deploy on Cloudflare Pages or Vercel.

## 1. Intent

The owner asked for a spec and a viewable repo for Paco's Island. It's a daily answer game with Krillion style rarity scoring on bounded answer lists. Paco takes the player by boat from Puerto Vallarta to Yelapa, by ATV, or on a dive. Trips open with lifetime points. v0.5 has no sign in.

Design calls the owner made in this run:

- Coalition's style in daytime Banderas Bay colors.
- Fonts from his archive in place of Coalition's.
- no-slop-ui wins when it disagrees with Coalition.
- PixiJS pixel art, like Coalition.

He also asked that his editorial suite be used on the copy.

## 2. Action

- Read Coalition's repo for its fonts, color tokens, sprite method (character grid sprites painted to canvas, nearest neighbor in Pixi 8) and screenshots.
- Read no-slop-ui's SKILL.md, banned patterns and review checklist, and vendored them in `.agents/skills/no-slop-ui`.
- Rendered the owner's archive fonts side by side. Picked PP Fuji Bold for the wordmark and numbers and PP Neue Montreal for reading text, since both come from one foundry.
- Built nine answer lists, a rule generator, six handwritten questions, 218 questions in all, and a fixed schedule of 21 days.
- Built matching (aliases, real alternate names, typo tolerance) and scoring (10 + 90 × share more common), with a familiarity guess blended into real counts.
- Built the three trips, with stops taken from water taxi, Yelapa and dive site sources, and drew the pixel art in code.
- Built saved progress, Move my progress links, share text and the end of day reveal.
- Added an optional Cloudflare Pages Function with a D1 table for counting answers across players.
- Installed plain-language-default and wrote the project rules into AGENTS.md.

## 3. Checks

- `node tools/check.mjs`: list sizes (193, 50, 32, 118, 30, 32, 30, 32, 40), 43 landlocked UN members, no alias pointing to two items, every answer matches itself, no day repeats a list. 0 problems.
- Played a full day in headless Chrome at 390 × 844: wrong answers, the clock, a typo, results, the end screen and the reveal. No page errors. The only console errors are expected 404 and 501 responses from `/api/answers` on a static server, after which the game falls back to estimates as designed.
- Rendered each trip at several scores and reviewed the screenshots. Then zoomed the scene from 320 × 160 to 240 × 120 because Paco was too small to read, and redrew Los Arcos as rounded islets with an arch.
- Contrast: white on bay 8.4:1, ink on sun 9.9:1, sun on bay 5.3:1, coral on bay 4.6:1.
- Copy: prosekeep check passed with 0 findings. plain-language-default flagged one long sentence, which was an artifact of the export joining labels. red-pen-editor inspect flagged repeated question templates, which are different questions on purpose. The intro was rewritten as connected sentences.
- The no-slop-ui checklist passed, with the hard shadow on the wordmark kept as part of Coalition's title style.

## 4. Gaps

- The answer function was not run against a live D1 database in this run.
- Familiarity tiers are hand set.
- The answer counter trusts the client.
- PP font licenses for a new site need the owner's confirmation.
- 21 days of questions before repeats.
